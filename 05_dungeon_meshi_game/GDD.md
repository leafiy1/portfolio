## 1. 游戏概述

### 1.1 一句话定位
以《迷宫饭》世界观为背景的**轻量 Roguelike × 美食收集**网页游戏：下迷宫、打魔物、把魔物做成料理吃掉，用"吃"驱动整条成长线。

### 1.2 核心体验
- **决策有意义**：探索选层、战斗选目标/技能/逃跑、事件多选、食材烹饪/食用时机。
- **反馈及时**：即时伤害飘字、克制/暴击/连击特效、成就与评级弹窗、场景配乐切换。
- **惊喜不断**：隐藏菜谱"食材组合解锁"、随机事件、宝箱/陷阱/BOSS 遭遇。
- **进步可见**：等级/经验、图鉴收集进度、厨神评级、周目循环、31 枚成就徽章。
- **难度匹配**：层数线性加深 + 周目指数提升，配合装备/料理养成曲线。

### 1.3 平台与技术
- 纯前端单文件网页（HTML+CSS+JS+内联 SVG），**无外部依赖、无构建步骤**。
- 双击 `file://` 或本地 HTTP 服务均可运行；localStorage 存档。
- 配乐为迷宫饭 TV 版 OST（本地 `ost/` 目录，需 HTTP 环境播放，file:// 自动静音不报错）。

## 3. 核心循环

```
选择层数 → 探索(消耗饱腹度/体力)
   ├─ 战斗（属性克制/技能/逃跑）
   ├─ 事件（多选分支/奖励/风险）
   ├─ 宝箱（金币+随机食材）
   ├─ 陷阱（惩罚）
   └─ 商人（金币换补给）
        ↓
   获得食材/金币/经验
        ↓
   烹饪食堂：食材 → 料理（厨神评级 S/A/B/C）
        ↓
   食用料理恢复 HP/饱腹度 → 再次深入
        ↓
   层内探索达标 → 挑战该层 BOSS → 解锁下一层
        ↓
   击败终局 BOSS 饕宴王 → 通关 → 进入下一周目（难度 ×1.3）
```

## 4. 数值设计

### 4.1 魔物强度（统一公式，全 31 种魔物一致）
```
魔物强度 = 周目倍率 × 层数倍率 × BOSS 加成
周目倍率 = 1.3 ^ (周目 - 1)
层数倍率 = 1 + (层数 - 1) × 0.18      // 每深一层 +18%
BOSS加成  = 1 + 0.3                    // 仅 BOSS 额外 +30%
```
- HP / 攻击 按公式缩放；防御不随周目缩放（保证玩家养成后仍能打出伤害）。
- 示例：1 周目第六层小怪倍率 1.9；饕宴王倍率 2.2 → HP 600×2.2=1320、ATK 40×2.2=88。

### 4.2 玩家成长
- **等级/经验**：`升级所需经验 = 20 × 1.55^(Lv-1)`；`胜利经验 = (12 + 层数×6) × 1.25^(周目-1)`。
- **每级成长**：攻击 +22%、HP 上限 +14%；升级按比例回血。
- **装备**：武器/防具各 4 档（铁制短剑 +4 → 屠龙宝刀 +30；皮甲 +3 → 龙鳞甲 +22），全队共享。

### 4.3 战斗结算
- 普通攻击：`(ATK - 敌DEF×0.5 + 随机(-2,6)) × 1.2`
- 技能攻击：`ATK × 技能倍率 - 敌DEF×0.3 + 随机(0,5)`（技能倍率 1.8~2.5，带冷却）
- 属性克制：六系循环 `火→冰→雷→土→圣→暗→火`；克制 ×1.8、被克 ×0.6
- 厨具特攻：森西（厨师）对不死系 ×2
- 暴击 ×2（基础 15%，半身人 20%）；连击：同一角色连中 3 次追加一次伤害
- 饥饿惩罚：饱腹 ≤30 攻击 ×0.7，=0 攻击 ×0.5 并持续扣血；诅咒（事件获得）攻击 ×0.8

### 4.4 厨神评级（烹饪系统核心反馈）
```
评级 = f(全队 HP 均值, 饱腹均值)
S：HP≥99.9% 且 饱腹≥70%（+15 金币奖励）
A：HP≥60% ｜ B：HP≥30% ｜ C：其余
```
- 评级推动玩家"先吃好再下厨"，形成战斗→补给→烹饪的正循环。

## 5. 经济系统

| 维度 | 内容 |
|------|------|
| 收入 | 战斗掉落（每魔物 gold 区间）、宝箱（15~45）、事件奖励、S 级烹饪 +15 |
| 支出 | 装备（60~380 金币）、消耗品（20~80 金币）、事件分支（如陪喝酒、献祭） |
| 风险 | 团灭损失 30% 当前金币 |
| 掉落 | 每魔物 1~3 种食材，战利品在战斗界面/图鉴可查 |
| 平衡 | 一层 5 场战斗≈100~150 金币，可买第一件武器；深层 BOSS 一次 120~600 金币，支撑高级装备 |

## 6. 层级与周目设计

### 6.1 六层迷宫总览
| 层 | 名称 | 主题 | 疲劳 | BOSS |
|----|------|------|------|------|
| 1 | 苔藓回廊 | 新手层，温顺魔物 | 8 | — |
| 2 | 石像大厅 | 石像/不死/料理魔物 | 11 | — |
| 3 | 龙之深渊 | 火系与不死 | 14 | 迷宫之主 |
| 4 | 硫磺炼狱 | 火系高危 | 17 | 硫磺龙 |
| 5 | 深渊食堂 | 黄金锅所在 | 20 | 守锅巨像 |
| 6 | 黄金盛宴厅 | 终局：饕宴王的宴会厅 | 23 | 饕宴王 |

### 6.2 解锁规则
- 第 1 层默认开放；第 N 层需**上一层探索次数 ≥ 3+N**；
- BOSS 守门层（4/5/6）额外要求击败上一层 BOSS（迷宫之主/硫磺龙/守锅巨像）。
- 每层探索 ≥3 次后出现该层 BOSS 挑战入口，也可在探索中 15% 概率随机遭遇。

### 6.3 周目循环
- 击败终局 BOSS 饕宴王 → 通关弹窗 → 进入下一周目。
- 下一周目：魔物 HP/攻击 ×1.3；保留图鉴/菜谱/食材/成就/金币；重置层数进度、队伍等级与装备；主线任务重置为 q1。

## 8. 系统设计要点

### 8.1 战斗
- 单敌 + BOSS 召唤多敌（最多 6 目标），可切换目标；四名队员可切换行动者。
- BOSS 技能：AOE 重创 + 召唤小怪（迷宫之主召骷髅、硫磺龙召炎魔、守锅巨像召锅铲小兵、饕宴王召残宴幽灵）。

### 8.2 探索
- 每层权重不同（战斗 45%~55%、宝箱/陷阱/商人/事件 5%~20%），事件 42 个（含 12 个新增：6 个 v2.2 内容 + 6 个 v2.4 小队小剧场），支持奖励/损失/战斗分支。

### 8.4 视觉设计系统（v2.4 重做）
- **美学方向**：暖中世纪奇幻食堂/冒险手账——暖米色羊皮纸底色 + 墨色文字 + 陶土橙单一强调色（#b4552d），明确弃用紫蓝渐变与玻璃拟态泛滥。
- **字体阶梯**：展示（标题）/ 标题 / 正文（16px）/ 辅助（13px 起）四级；正文不低于 15px；手账风楷体用于开场白、食欲文案、生态观察等"便签"文案。
- **统一语言**：战斗/烹饪/图鉴/成就/商店共用同一色板、圆角刻度（8/12/16/999）、双层/三层阴影与动效曲线；卡片内边距 22px+，层级化留白。
- **标题屏**：盾形纹章（黄金锅 + 交叉餐叉勺）+ 大字分层阴影 + 便签式开场白 + 四主角头像 + 版本徽标。
- **反馈细节**：战斗伤害飘字（普通/暴击/克制/连击/敌方伤害）、厨神评级墨印印章、成就徽章卡片与弹窗、敌人受击抖动 + 血条闪光。
- **可访问性**：自定义焦点环、`prefers-reduced-motion` 降级、禁用态与空状态文案。

### 8.3 存档
- localStorage 自动存档（每次关键操作后），标题界面支持继续/新游戏/重置；读档重置技能冷却，保证状态一致。

## 11. 技术架构与可维护性

- **单文件交付**（`index.html`，约 230KB）：满足"双击即玩/无依赖"的作品集与面试演示诉求；内部按模块分区注释：
  `数据定义(角色/魔物/菜谱/事件/成就) → 工具 → 状态 → 渲染 → 战斗 → 烹饪 → 存档 → 音效/音乐 → 引导`。
- 如需进一步拆分（团队协作场景），可平移为 `js/game-data.js`（纯数据）+ `js/game.js`（逻辑）+ `index.html`（结构/样式/内联 SVG），脚本按序加载即可，file:// 与 HTTP 均不受影响。
- 美术资产（角色头像 PNG、内联纹章 SVG、OST MP3）路径约定为 `assets/`、`ost/`，页面内相对路径引用。
