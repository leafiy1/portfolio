## 采集来源

- 电商价格/图片：慢慢买手机版全网比价页 `https://s.manmanbuy.com/m/search/result?keyword=...&c=search`
  - 页面标注京东 / 天猫 / 淘宝 / 拼多多 / 抖音小店等平台；
  - 每条命中记录 `search_url`、`platform`、`match_title`、`price`、`captured_at`。
- 官网产品图：品牌官网产品页 `og:image` / `twitter:image`，记录 `image_evidence_v7.json`。
- 红线：不估算；标题未命中型号核心词的记录不写入正式库；配件/脚贴/耳机套/防尘罩等误匹配已二次清洗。

## 可复跑脚本

```bash
node gear/tools/enrich_prices.cjs --limit 0 --offset 0 --workers 3 --delay 300
node gear/tools/cleanup_evidence.cjs
node gear/tools/enrich_images.cjs --limit 0 --offset 0 --workers 4 --delay 150
node gear/tools/embed_products.js
```
