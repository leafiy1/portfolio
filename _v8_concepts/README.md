# 主站 v8 方案原型

> 状态：3 个方向已出可打开的原型，不改线上 `index.html`。
> 目标用户：制造业 AI/数字化方向面试官，快速判断「这个人会不会做产品、证据是否经得起追问」。

## 三个方向

| 方向 | 文件 | 设计主张 | 适合场景 |
| --- | --- | --- | --- |
| A 证据账本 | `direction-a.html` | 暖中性编辑风，侧栏身份 + 证据表，面试官 30 秒扫清项目状态 | 保守稳妥、信息密度高 |
| B 产品运营舱 | `direction-b.html` | 深色运营台，数据优先、状态明确，像内部产品看板 | 强调数据策略/Agent 落地 |
| C 案例刊物 | `direction-c.html` | 杂志式长卷，把项目当案例深度讲，重视叙事与作品感 | 突出产品判断和设计品味 |

## 正常流程

1. 需求与用户：面试官要在 2-5 分钟内确认「做过什么、怎么证明、是否真实」。
2. 信息架构：身份 → 核心结论 → 项目证据 → 简历/联系方式。
3. 数字口径：统一用 GearPick 234、葉光館 3,358、迷宫饭 70 图鉴、办公 Agent 本地管线 20 条评测。
4. 视觉验证：Playwright 桌面/移动截图，检查溢出、重叠、证据标签可读性。
5. 选定方向后再改正式 `index.html`，本轮不动。
