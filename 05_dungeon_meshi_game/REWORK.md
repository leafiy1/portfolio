# 迷宫饭 · 回炉重造方案

> 2026-08-18 根据真实试玩反馈立项：当前版本“内容太少、指引不好、关卡设计不合理、魔物种类少、装备与战斗缺乏关联”，不能小修，按产品重做推进。

## 问题拆解

| 反馈 | 现状 | 重造方向 |
| --- | --- | --- |
| 内容太少 | 6 层 / 31 魔物 / 39 菜谱 | 增加魔物、事件、隐藏路线与层内目标，让每层都有“这层为什么值得打” |
| 指引不好 | 3 步文字教学 + 主线任务栏 | 改成 5 步可高亮教学 + 常驻“当前目标/下一步”提示 |
| 关卡设计不合理 | 解锁主要靠探索次数 | 改为目标驱动解锁：明确 BOSS 条件、层内事件、奖励预览 |
| 魔物种类少 | 部分层只有 4-5 种 | 每层扩充到 6-8 种，增加稀有怪与特殊战利品 |
| 装备无关联 | 装备只在商店购买，战斗掉落没有装备 | 魔物/BOSS 掉落装备，装备与食材、层数、Boss 强关联 |
| 音乐可圈可点 | OST 完整 | 保留并围绕音乐强化场景切换 |

## 重造闭环

1. 新手引导与目标系统
2. 魔物扩充与层内目标
3. 装备掉落与战斗内嵌
4. 关卡解锁与 BOSS 路线重做
5. 新内容、事件、隐藏路线
6. 真实试玩回归
