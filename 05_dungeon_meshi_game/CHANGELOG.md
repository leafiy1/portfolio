## v2.0.0 — 完整版（2026-08-02）

### 用户原始需求（原文回溯）
- 做一个「迷宫饭风」的中世纪奇幻互动网页游戏：玩法+前端+UI+美术
- 玩法、美术要多做；要好玩（决策有意义/反馈及时/惊喜不断/进步可见/难度匹配）
- 加开场载入动画、主线引导；字体贴合原著、背景加中世纪元素、配乐用迷宫饭TV版OST
- 音量控制、UI位置、音乐平滑切换、自动播放

### 最终交付
单文件 `index.html`（191KB）+ `ost/` 18首精选OST（39MB），HTTP 服务运行。

### 功能清单
| 模块 | 内容 |
|------|------|
| 迷宫 | 5层（苔藓→石像→龙渊→硫磺→深渊食堂） |
| 魔物 | 25种（含3 BOSS：迷宫之主/硫磺龙/守锅巨像） |
| 菜谱 | 20道（含8隐藏菜谱，食材组合解锁） |
| 事件 | 30个随机事件（多选分支） |
| 成就 | 20个徽章 |
| 战斗 | 属性克制六系、暴击、连击、多敌、BOSS技能 |
| 收集 | 图鉴30食材、厨神评级S/A/B/C |
| 系统 | 存档/读档（localStorage）、周目循环（难度×1.3/周） |
